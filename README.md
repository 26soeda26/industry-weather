# Industry Weather（業界の市場天気予報）

業界の名前を入れるだけで、**公開情報だけ**からその業界の需要見通しを
「天気予報」の形でまとめるツールです。

| 期間 | 見る先 |
|---|---|
| 短期 | 半年先 |
| 中期 | 3〜4年先 |
| 長期 | 2030〜2040年 |

それぞれを ☀️ 晴れ ／ ☁️ 曇り ／ 🌧️ 雨 で示し、根拠となった公開情報の出典を付けます。

## なぜ作ったか

私は電子部品メーカーに勤めていて、本業のかたわら、公開情報だけで市場を予測する
月刊レポートを社内向けに書いています。業界新聞にもない視点だと社内で反響があり、
「これは自分の業界だけでなく、どの会社でも欲しいはずだ」と思いました。

専門の調査会社に頼まなくても、会社員が自分の業界の天気予報を毎月受け取れる。
それを目指しています。

## 使い方

    pip install -r requirements.txt
    export ANTHROPIC_API_KEY=（あなたのAPIキー）

業界名と、主なお客さんの業界を入れて実行します。

    # 高齢化とともに伸びる業界
    python weather.py "介護用品" --customers "介護施設,在宅介護"

    # ドライバー不足に直面する業界
    python weather.py "トラック物流" --customers "EC,小売"

    # 海外に挑む伝統産業
    python weather.py "日本酒" --customers "国内飲食店,海外輸出"

`output/` フォルダに HTML のレポートができます。

## 仕組み

1. Claude API の Web 検索で、政府統計・業界団体の統計・上場企業の決算資料・業界ニュースを集める
2. 短期・中期・長期の3つに分けて予報を書く
3. 実際に検索で見つかったページだけを出典として表示する（URLの作り話を防ぐため）
4. HTML のレポートに仕上げる
